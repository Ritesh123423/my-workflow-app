Date & Escalation Defaults

This setting controls how ALL ROUs under this company are computed and displayed. It is a master switch — flipping it instantly changes every schedule view, computation, and export for this company. You can switch back and forth freely; nothing is destroyed. Each ROU's saved data is preserved either way.
📅 Default (Month Number)
  • Schedule = N equal lease-month buckets (start-day to start-day-1)
  • Row dates = lease commencement + (m-1) months
  • Custom escalation steps entered as Month 1, 2, 3…
  • No proration — every row gets the full monthly rent
  • Same depreciation, PV, interest, SD logic as the original engine
📆 Calendar Period
  • Schedule aligns to actual calendar months
  • Row dates = end-of-month (arrears) or start-of-month (advance)
  • Partial first/last months pro-rated by days (e.g. 10/30)
  • Custom escalation steps entered as From-Date → To-Date
  • Security Deposit dates & periods auto-align with rent rows
  • PV, interest, depreciation, export — all driven by these dates
